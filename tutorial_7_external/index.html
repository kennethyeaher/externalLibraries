    The shared integration pattern

    1. CDN Include a specific library version.
    2. Check Verify the library is available.
    3. Process Shape the shared records for each view.
    4. Initialize Create the chart, map, or animation.
    5. Error handling Keep useful text when an enhancement fails.

    Choosing a library for Project 2

    Choose Chart.js when the task is comparing counts, ratings, or trends. Choose Leaflet when verified locations and geographic filtering help someone decide. Choose GSAP when a coordinated transition explains a meaningful change that simpler CSS cannot handle well.

    For this dataset, Chart.js is the strongest starting point: cuisine and rating already exist. Leaflet first needs real coordinates. Animation supports the experience but does not add new information.
